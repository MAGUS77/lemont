### 2️⃣ PUBLICAR EN LA WEB (GRATIS)

**Elige UNA opción:**

#### A) GitHub Pages (Recomendado)
1. Crea cuenta en [github.com](https://github.com)
2. Nuevo repositorio "New Repository"
3. Sube `index.html`
4. Activa Pages en Settings
5. Tu URL será: `https://tuusuario.github.io/feedback-lemon`

**Ventaja:** Muy fácil, todo automático

#### B) Vercel
1. Abre [vercel.com](https://vercel.com)
2. "Create" → Importa tu GitHub
3. **¡Automático en segundos!**

**Ventaja:** Velocidad, análitica gratis

#### C) Netlify
1. Abre [netlify.com](https://netlify.com)
2. "Add new site" → Importa tu GitHub
3. **¡Público en minutos!**

**Ventaja:** UI más amigable

## 🆘 SI ALGO FUNCIONA MAL

**"No recibo emails"**
1. Revisa SPAM
2. Confirma el email en el link que FormSubmit te mandó
3. Espera 5 minutos

**"La URL no funciona"**
1. Espera 5 minutos (toma tiempo propagarse)
2. Limpia caché: Ctrl+F5 (o Cmd+Shift+R en Mac)

**"Los cambios no se ven"**
1. Si editaste el HTML, sube el archivo modificado
2. Ctrl+F5 para refrescar caché
3. Espera a que GitHub/Vercel lo procese
