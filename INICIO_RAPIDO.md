# 🚀 GUÍA RÁPIDA - 5 MINUTOS

## PASO 1: Descargar
- Descarga el archivo `index.html`

## PASO 2: Probar Localmente (Tu PC)
- Doble clic en `index.html`
- Se abrirá en tu navegador
- ¡Ya está testado!

---

## PASO 3: Publicar GRATIS en Internet

### Opción A: GitHub Pages (MÁS FÁCIL)

1. Abre [github.com](https://github.com) → "Sign up" (si no tienes cuenta)
2. Crea nuevo repositorio: "New" → nombre: "feedback-lemon" → "Create"
3. Dentro del repositorio: "Add file" → "Upload files" → arrastra `index.html`
4. En la carpeta: "Settings" → "Pages" → Source: main → "Save"
5. Tu web estará en: **https://tuusuario.github.io/feedback-lemon**

✅ **¡Listo! Comparte ese enlace**

---

### Opción B: Vercel (AUTOMÁTICO)

1. Ve a [vercel.com](https://vercel.com) → "Sign up with GitHub"
2. "Create" → "Import Git Repository" → selecciona tu repo
3. **¡Se despliega automáticamente en segundos!**

---

## PASO 4: Configurar Email

1. Abre `index.html` con un editor (Notepad, Word, etc.)
2. Busca: `const emailDestino = 'pedrodelmonte235@gmail.com';`
3. Reempliza por tu email: `const emailDestino = 'mi-email@gmail.com';`
4. Guarda

---

## PASO 5: Configurar URL Cuchillería

1. En el mismo archivo, busca: `const urlCuchilleria = 'https://www.gomezpamplona.com';`
2. Reempliza por tu URL o la URL de Google Review
3. Guarda

---

## PASO 6: Subir Cambios a Internet

Si publicaste en GitHub:
1. Entra a tu repositorio en GitHub
2. "Add file" → "Upload files" → arrastra `index.html` modificado
3. "Commit changes"
4. **En 30 segundos tu web estará actualizada**

Si usas Vercel:
1. Los cambios se sincronizan automáticamente desde GitHub
