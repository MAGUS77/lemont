# 🍋 Lemon Feedback - Sistema de Valoraciones

Formulario de feedback interactivo y profesional para Cuchillería Gómez Pamplona.

## ✨ Características

- ⭐ Sistema de valoración por estrellas (1-5)
- 📧 Envío automático de emails para valoraciones bajas (1-3 estrellas)
- 🔗 Redirección automática para valoraciones altas (4-5 estrellas)
- 📱 Diseño completamente responsivo (móvil, tablet, desktop)
- 🎨 Interfaz moderna con animaciones suaves
- ✅ 100% gratuito y sin dependencias externas

## 🚀 Inicio Rápido

### Opción 1: Usar Localmente
Simplemente descarga `index.html` y abre en tu navegador con doble clic.

### Opción 2: Publicar en GitHub Pages
1. Crea un repositorio en GitHub
2. Sube `index.html`
3. Activa GitHub Pages en Settings
4. ¡Listo! Tu web estará en: `https://tuusuario.github.io/feedback-lemon`

### Opción 3: Publicar en Netlify
1. Descarga `index.html`
2. Ve a [netlify.com](https://netlify.com)
3. Arrastra `index.html` a Netlify
4. Tu web estará disponible en segundos

## 📧 FormSubmit

Esta web usa FormSubmit.co para enviar emails automáticamente.

**Primer envío:**
1. El usuario completa el formulario
2. Se envía a FormSubmit
3. Recibirás un email de confirmación
4. Haz click en el link para confirmar tu email

**Envíos posteriores:**
- Automáticos a tu bandeja sin confirmación adicional

## 🔒 Privacidad y Seguridad

- Solo se envían: nombre, apellido, valoración y comentario
- Los datos se transmiten por HTTPS
- FormSubmit es un servicio seguro y confiable
- No se almacena información sensible
